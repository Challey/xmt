# 短闻（XMT 核心阅读产品）

产品名：**短闻**（原「短新闻」）。路径：`/read`。

## 战略定位：第三种短内容模式

| | 抖音 | 视频号 | **短闻（信流）** |
|--|------|--------|------------------|
| 驱动 | 娱乐上头 | 社交正能量 | **可信节奏** |
| 形态 | 竖滑视频 | 竖滑视频 | **竖滑短文 + 可核验来源** |
| 粘性 | 算法连刷 | 关系链 | **今日节奏 + 信流连读 + 稍后** |
| 严肃性 | 弱 | 中 | **强（徽章 / 溯源 / 原文）** |

一句话：**短平快可读，来源可核，愿意连刷。**

双模：

| 模式 | URL | 说明 |
|------|-----|------|
| **信流** Immersive（**默认** / 粘性核心） | `/read` | 一屏一条竖滑；`?mode=browse` 切速览 |
| **速览** Browse | `/read?mode=browse` | 卡片列表摘要 |
| 详情 | `/read/{nid}` | 关键摘要 → 要点 → 提要 → 原文 |
| 今日 | `/read/today` | 当日速览 |
| 稍后 | `/read/later` | 本机 / 登录同步 |

首页与主导航将 **短闻** 置于核心入口（菜单靠前；首页主 CTA 为「进入信流」）。

## 信息架构细节

筛选：

- 信任：`?level=trusted|official|enterprise|aggregate`
- 领域：`?domain=` — **热点行业目录**见 [domains.md](domains.md)；主行默认露出 **财经**（民生）+ 硬科技热门，其余「更多」折叠
- 信源：`?source=`
- 已读 / 稍后 / 键盘快捷键：见产品页 hint（`i` 切换速览↔信流）

API / RSS 路径未改（兼容）：

- `GET /api/xmt/v1/short-read?...`
- `/read/rss.xml?...`

## 视觉

- **白天 / 黑夜**：顶栏与首页可切换；偏好存 `localStorage`（`xmt_duanwen_theme`：`day`|`night`|`system`）
- 速览白天：浅灰底 `#f5f5f7`、Outfit + Noto Sans SC、Apple 蓝强调 `#0071e3`
- 黑夜 / 信流夜间：纯黑底、毛玻璃顶栏、上滑提示；**信流是布局**（竖滑），颜色跟主题走
- 卡片左侧可信轨（蓝→绿）提醒「可核验」
- 顶栏在速览与信流均为 sticky，减少操作成本

## 粘性（本机）

- `localStorage` 已读 / 稍后（登录可同步）
- **今日节奏**：当日已读条数气泡（`xmt_duanwen_streak`）
- 主行领域芯片：**财经 · 科技 · 国内 · 国际**（国内为 `gov|society|military` 聚合；国际为 `world`）

## 验收

1. `/read` 品牌为「短闻」，3 秒内可读摘要；可切换白天/黑夜  
2. 「信流」竖滑连续 ≥5 条，徽章与溯源可见  
3. 首页展示财经 / 科技 / 国内 / 国际最热条目，1 步进入信流  
4. 主导航「短闻」权重靠前
